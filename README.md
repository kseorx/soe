# S&OE demo

Демонстрационный операционный пульт, который показывает механику S&OE из питч-дека: как выявляется риск, как выбираются приоритетные кейсы и какие действия разрешены на текущем этапе поставки. Это синтетическая модель на Streamlit, а не подключённая production-система или Power BI-отчёт.

## Что показывает демо

- Панель проблем с фильтрами по БЕ и категории, очередью до 8 кейсов по сумме риска и карточкой выбранного события
- Экспресс-трек до 48 часов для таможенных/дефектных событий и сдвига ETA более чем на 5 дней
- Сценарное сравнение стоимости, дефицита и выполнения спроса; выбор недорогого допустимого варианта через PuLP/CBC
- Этапы поставок, зоны заморозки, разрешённые меры и недельный цикл: данные → регионы → импорт → совещание → исполнение
- Аналитические срезы продаж и запасов
- Отдельная вкладка с целями, контрольными точками и критериями приёмки из питч-дека; они явно отделены от синтетического факта

Синтетический контур содержит 30 SKU, 5 самостоятельных региональных дивизионов и отдельную БЕ «Импорт», 2 распределительных центра, 24 заказа, 20 партий и 40 событий. Названия дивизионов нумерованы, так как презентация не задаёт реальные имена.

Правила распределения демонстрационно исполняемы: отказ от firm-заявки показывает компенсацию на примере журнала высвобождений; дополнительный импорт ограничен 10% подтверждённых заявок; доступный лот распределяется так, чтобы выравнивать покрытие в днях, не выходя за firm-заявки. Изменение объёма на этапе производства явно отнесено к S&OP.

Проверка эффекта отображает три среза: пилотные категории против контроля, волна 1 против волны 2 и текущий сезон против предыдущего.

## Запуск

```bash
cd /Users/xeroks/Projects/soe
python3 -m venv .venv
. .venv/bin/activate
python -m pip install -r requirements.txt
streamlit run app.py
```

Streamlit напечатает локальный URL и выберет следующий свободный порт, если стандартный уже занят.

## Основные файлы

- app.py — точка входа
- src/model.py — генерация данных, правила fast-track и сценарные расчёты
- src/ui.py — панель проблем, поток решений, аналитика и цели пилота
- tests/test_model.py — регрессионные проверки модели
